1. Foundational Concepts of Generative AI (10 Marks)Generative AI refers to a class of artificial intelligence systems that can create new content such as text, images, audio, and video by learning patterns from existing data.

Key foundational concepts:

- Probabilistic Modeling: Learns the statistical distribution of data and generates new samples by sampling from this distribution.
- Neural Networks: Deep learning models, especially with many layers, form the backbone of generative AI.
- Latent Space Representation: Input data is compressed into a lower-dimensional space, capturing its essential features. New data is generated by decoding points from this space.
- Training Objectives: Models are trained using techniques like maximum likelihood estimation, reconstruction loss, or adversarial loss to produce realistic outputs.
- Types of Generative Models:

    - Variational Autoencoders (VAEs) – Learn latent representations and generate data by sampling.
    - Generative Adversarial Networks (GANs) – Use two competing networks (generator and discriminator) to produce realistic data.
    - Autoregressive Models (e.g., GPT) – Predict next tokens in sequence, generating text step by step.

These concepts enable machines to go beyond recognition and classification, allowing them to create novel, realistic content.
2. Generative AI Architectures (Focus on Transformers) (10 Marks)Transformers are the most important architecture in modern generative AI, especially for text.

Key components of transformers:

- Self-Attention Mechanism: Allows the model to weigh the importance of each token in a sequence relative to others, capturing long-range dependencies.
- Positional Encoding: Adds information about token order since transformers process inputs in parallel.
- Encoder-Decoder Structure: Original transformers used both; many generative models (like GPT) use only the decoder.
- Layer Normalization & Feed-Forward Networks: Provide stability and expressiveness.
- Scalability: Transformers scale effectively with more data and compute, enabling large language models (LLMs).

Advantages over older models (RNNs, CNNs):

- Parallel processing → faster training.
- Better handling of long sequences.
- Superior performance in language tasks.

Transformers power models like GPT, BERT, T5, and are central to text generation, translation, and summarization.
3. Generative AI Applications (10 Marks)Generative AI has broad applications across industries:

- Text Generation: Chatbots, content writing, code generation, summarization (e.g., ChatGPT, Copilot).
- Image Synthesis: Text-to-image generation, photo editing, style transfer (e.g., DALL·E, MidJourney, Stable Diffusion).
- Audio & Music: Speech synthesis, music composition, voice cloning (e.g., WaveNet, Jukebox).
- Video Generation: Deepfakes, animation, text-to-video synthesis.
- Healthcare & Science: Drug discovery, molecular design, medical image synthesis.
- Data Augmentation: Creating synthetic data to improve AI model training.
- Personalization: Tailored marketing, education, and entertainment content.

These applications show how generative AI is transforming creativity, productivity, and problem-solving.
4. Impact of Scaling in Large Language Models (LLMs) (10 Marks)Scaling LLMs by increasing model size, data, and compute has significantly impacted generative AI.

Positive Impacts:

- Better Performance: More accurate, fluent, and contextually aware outputs.
- Emergent Abilities: Few-shot learning, reasoning, and code generation appear in large models but not small ones.
- Generalization: Large models adapt to new tasks with minimal fine-tuning.

Challenges:

- Resource Demands: Requires huge computational power and energy.
- Bias & Ethics: Larger models can amplify biases present in training data.
- Interpretability: Harder to understand how decisions are made.
- Deployment Costs: High infrastructure requirements.

Research Directions:

- Efficient scaling methods (e.g., mixture-of-experts, sparsity).
- Reducing environmental impact.
